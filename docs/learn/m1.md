## Part 1: The theory

### 1.1 What are we pricing?

A **European call** with strike $K$ and expiry $T$ pays $\max(S_T - K, 0)$ at time $T$. A **put** pays $\max(K - S_T, 0)$. "European" means you can only exercise at $T$ (American options come in M3).

The question: what is that payoff worth *today*?

### 1.2 The model for the stock

Black-Scholes assumes **geometric Brownian motion**:

$$dS_t = \mu S_t\,dt + \sigma S_t\,dW_t$$

In words: each instant the stock's *percentage* return has a drift $\mu$ plus random noise of size $\sigma$. The solution is

$$S_T = S_0 \exp\!\left((\mu - \tfrac12\sigma^2)T + \sigma\sqrt{T}\,Z\right), \quad Z \sim N(0,1).$$

So $\ln S_T$ is normal. (The $-\tfrac12\sigma^2$ is Itô's correction: without it, $\mathbb{E}[S_T]$ would not equal $S_0 e^{\mu T}$. You'll check this in Exercise 4.)

You already met this in the VaR project: it's the same GBM as your Monte Carlo model.

### 1.3 The big idea: hedging removes $\mu$

Hold one option and short $\Delta$ shares of stock. Choose $\Delta$ so that small stock moves cancel out. That portfolio is (instantaneously) riskless, so it must earn the risk-free rate $r$, or there is free money (arbitrage).

Consequence: the option price does **not** depend on $\mu$. Two investors who disagree about the stock's expected return still agree on the option price, because both can hedge.

### 1.4 Risk-neutral pricing

Since $\mu$ doesn't matter, set $\mu = r$ (pretend everyone is risk-neutral) and price by discounting the expected payoff:

$$C = e^{-rT}\,\mathbb{E}^{\mathbb{Q}}[\max(S_T - K, 0)], \qquad S_T = S_0 e^{(r - \frac12\sigma^2)T + \sigma\sqrt T Z}.$$

$\mathbb{Q}$ is the "risk-neutral measure": the same world, with probabilities reweighted so every asset grows at $r$ on average.

### 1.5 Doing the integral (outline)

The call pays only when $S_T > K$, i.e. when
$Z > -d_2$ with $d_2 = \dfrac{\ln(S/K) + (r - \frac12\sigma^2)T}{\sigma\sqrt T}$.

Split the payoff: $\mathbb{E}[(S_T - K)\mathbf{1}_{S_T>K}] = \mathbb{E}[S_T \mathbf{1}_{S_T>K}] - K\,\mathbb{Q}(S_T > K)$.

- Second term: $\mathbb{Q}(S_T>K) = \mathbb{Q}(Z > -d_2) = N(d_2)$.
- First term: completing the square in the exponent shifts the normal by $\sigma\sqrt T$, giving $S e^{rT} N(d_1)$ with $d_1 = d_2 + \sigma\sqrt T$.

Multiply by $e^{-rT}$:

$$\boxed{C = S N(d_1) - K e^{-rT} N(d_2)}$$

Try the "completing the square" step yourself (Exercise 5); it's a common interview question.

### 1.6 Put-call parity

Long call + short put (same $K$, $T$) pays $\max(S_T-K,0) - \max(K-S_T,0) = S_T - K$ always. A portfolio of one share and a loan of $Ke^{-rT}$ pays the same. Same payoff means same price:

$$C - P = S - Ke^{-rT}.$$

No model was used, only "no free money". From this the put formula follows:
$P = Ke^{-rT}N(-d_2) - SN(-d_1)$ (using $1 - N(x) = N(-x)$).

## Part 2: The code, line by line

Open `options_pricer/black_scholes.py`.

```python
from math import erf, exp, log, sqrt
```
Only the standard library. `log` is the natural log ($\ln$).

```python
def norm_cdf(x):
    return 0.5 * (1.0 + erf(x / sqrt(2.0)))
```
$N(x)$, the standard normal CDF. Python has no `norm_cdf` built in, but it has the error function $\operatorname{erf}$, and $N(x) = \tfrac12(1 + \operatorname{erf}(x/\sqrt2))$. (Most people use `scipy.stats.norm.cdf`; writing it yourself shows you know what it is.)

```python
def d1_d2(S, K, T, r, sigma):
    if S <= 0 or K <= 0 or T <= 0 or sigma <= 0:
        raise ValueError(...)
```
Guard clause: $\ln(S/K)$ needs $S, K > 0$, and we divide by $\sigma\sqrt T$, so both must be positive. Failing loudly beats returning `nan`.

```python
    d1 = (log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * sqrt(T))
    d2 = d1 - sigma * sqrt(T)
```
Direct transcription of the formulas. Note `**` is power in Python. Computing $d_2$ from $d_1$ avoids repeating the long expression.

```python
def call_price(S, K, T, r, sigma):
    d1, d2 = d1_d2(S, K, T, r, sigma)
    return S * norm_cdf(d1) - K * exp(-r * T) * norm_cdf(d2)
```
`d1, d2 = ...` unpacks the tuple returned by `d1_d2`. The return line is the boxed formula.

```python
def put_price(...):
    return K * exp(-r * T) * norm_cdf(-d2) - S * norm_cdf(-d1)
```
Put formula from 1.6.

```python
def put_call_parity_gap(...):
    return call_price(...) - put_price(...) - (S - K * exp(-r * T))
```
Should be 0. A tool for testing, not pricing.

### The tests (`tests/test_black_scholes.py`)

- `pytest.approx(x, abs=1e-4)` means "equal within 0.0001". Never compare floats with `==`.
- `@pytest.mark.parametrize("strike", [...])` runs the same test once per strike: 5 tests from one function.
- `with pytest.raises(ValueError):` passes only if the code inside raises that error.

Run them: `python -m pytest -q`. Then break something on purpose (change `+ 0.5` to `- 0.5` in `d1`) and watch which tests fail. That's the best way to see what each test protects.

**Ex 1 (code).** Price a 6-month call and put with $S=50$, $K=55$, $r=3\%$, $\sigma=30\%$. Check parity by hand.
<details><summary>Answer</summary>

Call ≈ 2.62, put ≈ 6.80. $C - P ≈ -4.18$ and $S - Ke^{-rT} = 50 - 55e^{-0.015} ≈ -4.18$. ✓
</details>

**Ex 2 (intuition).** Without running code: does a call get more or less valuable when $\sigma$ rises? When $r$ rises? When $T$ rises?
<details><summary>Answer</summary>

$\sigma$↑: more valuable (the upside grows, the downside is capped at 0). $r$↑: more valuable (paying $K$ later is cheaper in today's money). $T$↑: more valuable for a call on a non-dividend stock (more time for upside, cheaper strike). These are the signs of vega, rho and theta in M2.
</details>

**Ex 3 (limits).** What does `call_price` tend to as $\sigma \to 0$? Check with $\sigma = 10^{-6}$, $S=K=100$, $T=1$, $r=5\%$.
<details><summary>Answer</summary>

With no randomness, $S_T = Se^{rT}$ for sure, so $C \to \max(S - Ke^{-rT}, 0) = 100 - 100e^{-0.05} ≈ 4.877$.
</details>

**Ex 4 (math).** Show $\mathbb{E}[e^{\sigma\sqrt T Z}] = e^{\frac12\sigma^2 T}$, and hence why GBM needs the $-\tfrac12\sigma^2$ term.
<details><summary>Answer</summary>

For $X \sim N(0, v)$, $\mathbb{E}[e^X] = e^{v/2}$ (the normal MGF). Here $v = \sigma^2T$. So $\mathbb{E}[S_T] = S_0e^{(\mu-\frac12\sigma^2)T}e^{\frac12\sigma^2T} = S_0e^{\mu T}$. Without the correction the mean would be too high.
</details>

**Ex 5 (math, interview-style).** Show $e^{-rT}\mathbb{E}^{\mathbb{Q}}[S_T\mathbf{1}_{S_T>K}] = S\,N(d_1)$.
<details><summary>Hint</summary>

Write the expectation as $\int_{-d_2}^{\infty} S e^{(r-\frac12\sigma^2)T + \sigma\sqrt T z}\,\frac{1}{\sqrt{2\pi}}e^{-z^2/2}\,dz$. Combine exponents: $-\tfrac12 z^2 + \sigma\sqrt T z - \tfrac12\sigma^2T = -\tfrac12(z - \sigma\sqrt T)^2$. Substitute $u = z - \sigma\sqrt T$.
</details>

**Ex 6 (code).** Write a quick Monte Carlo check: simulate 1,000,000 values of $S_T$ under $\mathbb{Q}$ with NumPy, average the discounted payoff, and compare to `call_price`.
<details><summary>Answer sketch</summary>

```python
import numpy as np
rng = np.random.default_rng(0)
Z = rng.standard_normal(1_000_000)
ST = 100 * np.exp((0.05 - 0.5 * 0.2**2) * 1 + 0.2 * np.sqrt(1) * Z)
print(np.exp(-0.05) * np.maximum(ST - 100, 0).mean())  # ≈ 10.45
```
